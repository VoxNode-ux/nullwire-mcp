# gh-nullwire

GitHub CLI extension for [NullWire-MCP](https://github.com/VoxNode-ux/nullwire-mcp).

```bash
gh extension install VoxNode-ux/gh-nullwire
gh nullwire scan --discover
```

This folder is the content of the separate repository `VoxNode-ux/gh-nullwire`
(the repository name must start with `gh-`). It is a script extension: no
compiling and no per-release work, because it always fetches the newest stable
release on first use. On Windows it needs Git Bash (installed with Git for Windows).
