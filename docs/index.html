Install

macOS, Linux, Termux 
curl -fsSL https://voxnode-ux.github.io/nullwire-mcp/install.sh | sh -s -- --setup
Windows (PowerShell) 
irm https://voxnode-ux.github.io/nullwire-mcp/install.ps1 | iex

The installers check every download against the release’s SHA256SUMS.txt. Source, docs and other install methods (npm, pip, Homebrew, Docker): github.com/VoxNode-ux/nullwire-mcp.

More ways to install

Any platform

npm (needs Node.js) 
npx -y nullwire-mcp install --client all
Python (or: pip install nullwire-mcp) 
pipx run nullwire-mcp install --client all
Docker 
docker run -i --rm ghcr.io/voxnode-ux/nullwire-mcp
Go 1.26 or newer 
go install github.com/VoxNode-ux/nullwire-mcp@latest

macOS and Linux

Homebrew 
brew install VoxNode-ux/nullwire/nullwire-mcp
Nix 
nix run github:VoxNode-ux/nullwire-mcp
Arch Linux (AUR)
